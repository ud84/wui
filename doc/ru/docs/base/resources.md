# Ресурсы

Темы и локали — JSON-данные, которые загружает приложение. Для начала используйте
полный каталог `examples/demo/res` или `examples/hello_world/res` с изображениями.
Небольшие фрагменты тем в справочнике описывают отдельные контролы: поместите их
в массив `controls` и добавьте остальные разделы, необходимые приложению.

| Платформа | Ресурсы примеров |
| --- | --- |
| Windows | Встроены через `.rc`; поле `resource` темы изображения задаёт имя секции |
| Linux | `res/` рядом с исполняемым файлом |
| macOS | `Contents/Resources/res` в bundle; сначала проверяется рабочий каталог |
| WASM | Виртуальный `/res`, загружаемый из сопровождающего файла `.data` |

Поле `path` темы изображения указывает каталог файлов вне Windows. Используйте
явные пути: не рассчитывайте на раскрытие `~` оболочкой внутри JSON. Публикуйте
`.js`, `.wasm` и `.data` браузерного приложения из одной сборки.

После загрузки темы вызовите `window->update_theme()`. После загрузки локали
обновите подписи через `set_text()`/`set_caption()`: существующие строки не
переводятся автоматически. См. [темы](theme.md) и [локали](locale.md).

Настройки отделены от ресурсов для чтения. `create_config()` использует реестр
на Windows и INI-файл на остальных платформах. На desktop задавайте доступный
для записи путь; в WASM файлы живут в памяти и сбрасываются при перезагрузке страницы.
