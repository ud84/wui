# Обработка ошибок

Многие операции WUI сообщают об ошибке через `bool` и значение `error`:

```cpp
if (!window->init("Application", {-1, -1, 800, 600}, wui::window_style::frame)) {
    std::cerr << window->get_error().str() << '\n';
}
```

После загрузки изображений или создания ресурсов проверяйте `get_error()` контрола.
`error::is_ok()` проверяет состояние, `str()` форматирует компонент и сообщение.
Загрузчики тем и локалей также предоставляют ошибки; варианты загрузки по имени
принимают `error&`.

Это не гарантия полного отсутствия C++-исключений: выделение памяти, пользовательские
callback и некоторые вспомогательные API могут бросать исключения. WASM-сборка
явно включает их поддержку. Обрабатывайте ошибки на подходящей границе приложения.
