# Устройство приложения

WUI предоставляет общие C++-контролы и платформенный бэкенд окон и графики.
Начните с [Hello world](../howto/hello-world.md); более крупный пример —
`examples/demo`, он же [живой Showcase](https://libwui.org/wasm/demo/).

## Жизненный цикл

1. Инициализируйте `framework`, загрузите полную тему и локаль.
2. Создайте `shared_ptr<window>` и контролы, добавьте их с явными координатами.
3. Настройте callback, инициализируйте окно и вызовите `framework::run()`.
4. Для завершения приложения вызовите `framework::stop()`.

## Координаты и владение

Границы контрола — `{left, top, right, bottom}`, а не x/y/width/height.
Пересчитывайте их при изменении размера. `panel` рисует фон, но не владеет другими
контролами и не размещает их автоматически. Добавляйте контролы непосредственно
в окно в нужном порядке отрисовки.

Окно хранит контролы, контрол — слабую ссылку на родителя. Не захватывайте
`shared_ptr` контрола в его собственный callback: используйте `weak_ptr`.
Ссылки на локальные данные должны оставаться действительными до снятия callback.
См. [владение](../base/ownership.md).

## Взаимодействие

Для локальных действий используйте callback кнопок, ввода и select, для общих
событий — подписки окна. `subscribe()` возвращает ID для `unsubscribe()`.
Чекбокс меняет состояние до callback. Callback меню сейчас получает индекс
видимой строки, а не стабильный ID элемента. См. [события](../base/event.md)
и [контролы](../controls/all.md).

## Темы, локализация и фоновая работа

Шрифт в JSON-теме — объект. После загрузки темы вызовите `window->update_theme()`;
после загрузки локали явно обновите подписи приложения.
См. [ресурсы](../base/resources.md), [темы](../base/theme.md), [локали](../base/locale.md).

Меняйте UI в потоке обработки событий его окна. Callback таймера выполняется
в разных потоках на разных платформах. Для передачи фонового результата используйте
`window::emit_event()`. Перед добавлением worker изучите [потоки и таймеры](../base/multi-threading.md).

## Особенности платформ

[macOS](../howto/macos.md) и [WASM](../howto/wasm.md) используют общие контролы, но
отличаются упаковкой ресурсов, буфером обмена, сохранением настроек и системными
интеграциями. В браузере нет рабочих потоков WUI и постоянной файловой системы
по умолчанию. Диалоги и системный трей имеют платформенные особенности.
