# WUI (Window User Interface Library)

WUI — это кроссплатформенная библиотека для создания графического интерфейса пользователя на C++. Библиотека использует C++17 и имеет минималистичный API. В настоящее время поддерживается Windows (XP — 11) и Linux (glibc 2.23 и выше).

WUI разработана с целью предоставления разработчикам простого и эффективного инструмента для создания кроссплатформенных GUI-приложений на C++. Библиотека позволяет сосредоточиться на логике приложения, а не на особенностях реализации интерфейса для каждой платформы.

## Особенности

- Кроссплатформенность: поддержка Windows и Linux, в планах — macOS
- Минималистичный API, простота использования
- Общие интерфейсы для рисования и обработки событий, независимые от платформы
- Поддержка тем оформления и локализации
- Возможность создания и интеграции пользовательских контролов
- Управление конфигурацией приложения (реестр Windows, ini-файлы, JSON)

## Архитектура

Проект основан на трех ключевых сущностях:

- **Window** — окно, которое принимает системные события и управляет контролами
- **Control** — визуальный элемент интерфейса (кнопки, поля ввода и т.д.)
- **Graphic** — интерфейс для отрисовки, абстрагирующий платформо-зависимые методы рисования

### Плоская модель владения контролами

WUI использует плоскую модель владения контролами: все контролы окна владеются одним объектом-родителем (обычно классом диалога), который хранит их в `std::shared_ptr`. При уничтожении родителя все контролы автоматически освобождаются.

```cpp
class DialingDialog {
    std::shared_ptr<wui::window> window;
    std::shared_ptr<wui::text> text;
    std::shared_ptr<wui::image> image;
    std::shared_ptr<wui::button> cancelButton;
};
```

Этот подход обеспечивает:
- Простое управление памятью без ручного удаления
- Предсказуемый жизненный цикл контролов
- Отсутствие циклических ссылок
- Безопасность благодаря `std::shared_ptr`/`std::weak_ptr`

[Подробнее о плоской модели владения](doc/ru/docs/base/ownership.md)

### Плоская модель подписки на события

В WUI реализована модель **«плоской подписки»**: окно выступает в роли центрального диспетчера событий, а любой объект может подписаться на нужные ему события.

```cpp
// Подписка на события клавиатуры и системы
std::string sub_id = window->subscribe(
    [this](const wui::event& ev) {
        if (ev.type == wui::event_type::keyboard) {
            // Логика горячих клавиш
        }
    },
    wui::event_type::keyboard | wui::event_type::system
);

// Отписка по ID
window->unsubscribe(sub_id);
```

Преимущества:
- **Свобода от иерархии** — не нужно наследоваться от контролов для обработки событий
- **Гибкость** — любой объект может подписаться на события любого контрола
- **Управление временем жизни** — динамическая подписка/отписка через уникальный ID
- **Производительность** — подписчики хранятся в `std::vector` для кэш-локальности
